# 使用指南（Windows GUI 主流程）

这份文档面向“已经装好环境，准备实际使用”的用户。  
如果你还没装环境，先看 [INSTALL.md](./INSTALL.md)。

> **前提**：所有操作需先完成命令行依赖安装（`pip install -r requirements.txt`）和 `nmap` 安装。`start_gui.bat` 不会自动安装软件包，跳过此步直接双击会报错。

## 1. 推荐使用路径

当前项目推荐流程是：

1. 双击 `start_gui.bat`
2. 在 `资产发现` 页做主机发现
3. 在 `漏洞匹配与服务识别` 页独立做分析
4. 在 `规则库导入` 页管理本地规则
5. 在 `报告对比` 页比较两次分析结果
6. 在 `Web 报告中心` 页一键启动 Web 查看报告

## 2. 启动 GUI

### 2.1 双击启动

```text
start_gui.bat
```

### 2.2 命令行启动

```powershell
cd C:\path\to\intra_vuln_assessor
.venv\Scripts\activate
python main.py gui
```

## 3. 资产发现页

### 3.1 默认用法

1. 输入目标网段
2. 保持默认扫描方式 `递进式智能扫描（ICMP -> ARP -> SYN）`
3. 点击 `开始资产发现`

结果：

- 生成独立资产发现报告
- 写入资产发现历史
- 当前资产表显示本次发现到的主机

### 3.2 自定义扫描方式

如果你切到 `自定义扫描方式`：

- 高级参数区会自动展开
- 你需要手工填写 `icmp` / `arp` / `syn` 组合
- 可以单独测试一种方式，也可以两两组合

示例：

- `icmp`
- `icmp,syn`
- `arp,syn`

### 3.3 端口候选

- 资产发现页的端口候选只影响 `SYN` 相关发现
- 留空时会自动恢复到默认端口集合
- 可以点击 `恢复默认`

### 3.4 资产画像

资产发现页也支持选择资产画像文件。  
它的作用是：

- 给发现到的资产附加“重要性标注”
- 进入快照与报告展示

它不会改变：

- 主机发现数量
- 发现方式本身

## 4. 漏洞匹配与服务识别页

### 4.1 默认用法

1. 输入目标网段
2. 保持扫描预设为 `标准扫描（推荐）`
3. 点击 `开始服务识别与漏洞匹配`

结果：

- 独立调用 `nmap`
- 生成分析报告
- 刷新分析历史
- 展示服务表与漏洞表

### 4.2 三种扫描预设

- `快速扫描`
  速度优先，当前参数：`-sV -Pn --version-light`
- `标准扫描（推荐）`
  平衡速度与识别率，当前参数：`-sV -Pn --version-intensity 5`
- `深度扫描`
  指纹更完整，当前参数：`-sV -Pn --version-all`

GUI 里会实时显示当前预设参数说明。

### 4.3 高级参数

展开后可配置：

- 候选端口
- 额外 `nmap` 参数
- 资产画像文件
- 主动探测开关
- 少量弱口令尝试开关

### 4.4 主动探测与弱口令尝试

当前行为：

- `启用主动探测`
  覆盖 `Telnet / SNMP / Redis / FTP 匿名`
- `启用少量空密码/弱口令尝试`
  覆盖 `SSH / FTP / MySQL`

注意：

- 主动探测结果会进入最终报告和风险评分
- 关闭开关后，这些结果不会参与评分
- 弱口令尝试依赖 `paramiko` / `pymysql`

### 4.5 资产画像

分析页的资产画像会影响：

- `asset_criticality`
- 最终风险分
- 风险等级抬升/下调

清空后会回到默认重要性，不会残留到下一次扫描。

## 5. 规则库导入页

默认区域：

- 本地规则文件选择
- `merge` / `replace`
- 当前规则库摘要

高级区域：

- 远程 URL 更新

推荐：

- 毕设演示与论文截图优先使用本地导入
- URL 更新用于展示扩展能力，不建议对不可信来源使用

## 6. 报告对比页

默认只列出分析报告，不列纯资产发现报告。

流程：

1. 选择基线报告
2. 选择新报告
3. 点击 `执行历史报告对比`
4. 如有需要，再点击 `打开 Web 对比页`

对比结果会展示：

- 服务新增 / 消失 / 持续
- 漏洞新增 / 修复 / 持续
- 风险变化样例

## 7. Web 报告中心页

你可以在 GUI 内完成：

- 启动 Web
- 打开 Web
- 停止 Web
- 查看分析报告历史
- 删除选中分析报告

Web 端当前只负责：

- 报告查看
- 扫描详情
- 历史对比
- 删除报告

Web 端不再负责：

- 提交扫描
- 规则管理
- 扫描参数配置

## 8. 删除报告

当前支持两种删除路径：

- GUI 删除
  - `资产发现` 页删除资产报告
  - `Web 报告中心` 页删除分析报告
- Web 删除
  - 报告中心列表页
  - 扫描详情页

删除时会同时清理：

- 数据库记录
- 报告目录
- 关联快照

## 9. 推荐演示流程

如果你要现场演示，建议：

1. 先看 [demo_lab_guide.md](./demo_lab_guide.md)
2. 启动本地靶场
3. 在 GUI 跑一轮资产发现
4. 跑一轮默认分析
5. 再开启资产画像或主动探测跑第二轮
6. 用报告对比页展示差异

## 10. CLI 补充入口

GUI 是主路径，但 CLI 仍适合：

- 批量实验
- 论文复现
- 自动化自检

常用命令：

```powershell
python main.py history --limit 10
python main.py compare --base 1 --new 2
python main.py rules list
python main.py web --host 127.0.0.1 --port 5000
```
