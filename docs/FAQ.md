# FAQ（常见问题）

这份 FAQ 只保留当前版本最常见、最有价值的问题。

## Q1：为什么资产发现和漏洞匹配没有连着自动跑？

因为这是新版明确的模块边界。

- `资产发现` 页只负责发现主机和生成资产报告
- `漏洞匹配与服务识别` 页只负责分析和生成分析报告

这不是 bug，而是为了避免旧版本“一次扫描把所有功能一起跑完”的问题。

## Q2：为什么 Windows 下 ARP 经常被跳过？

ARP 在 Windows 下受多个条件影响：

- `scapy`
- `Npcap`
- 管理员权限
- 是否是真实局域网
- 当前是否启用了代理 / 虚拟网卡 / TUN/TAP

另外，如果你扫的是 `127.0.0.0/29` 这种回环靶场，ARP 本身也没有真实二层意义。

## Q3：为什么 SYN 单独发现不到主机？

在当前本地回环靶场下，这属于正常边界，不代表程序坏了。

原因通常是：

- 回环靶场不适合用 SYN 做资产发现演示
- 当前环境缺少原始报文权限
- 目标开放端口集合有限

## Q4：为什么分析页必须装 `nmap`？

因为这页的职责就是“服务识别与漏洞匹配”，核心依赖 `nmap -sV`。

如果 `nmap` 不可用：

- GUI 会直接报错
- 不会生成伪分析结果

## Q5：主动探测结果会不会影响风险分？

会。

只要你开启了主动探测：

- `FTP anonymous`
- `Redis 未授权`
- `SNMP 默认 community`
- `Telnet 开放`

这些结果都会进入同一套量化模型，与规则匹配结果一起评分。

## Q6：弱口令尝试会不会影响风险分？

也会。

如果开启了少量弱口令尝试，并且命中了：

- `SSH`
- `FTP`
- `MySQL`

对应结果会进入最终报告和风险评分。

## Q7：为什么资产画像有时看起来“没变化”？

资产画像不会改变：

- 主机数量
- 服务数量
- 端口开放结果

它改变的是：

- 资产重要性
- 最终风险分
- 风险等级的抬升或下调

## Q8：资产发现页也能选资产画像吗？

可以。

但它只用于：

- 在快照和报告里标注资产重要性

不会用于：

- 增加主机发现数量
- 替代扫描逻辑

## Q9：候选端口删空后怎么办？

当前 GUI 已经处理了这个问题：

- 端口为空时会自动恢复默认端口集合
- 你也可以手动点击 `恢复默认`

## Q10：为什么报告很多，怎么删除？

现在两边都能删：

- GUI：资产发现页和 Web 报告中心页
- Web：报告中心列表页和扫描详情页

删除会连带清理数据库记录和报告目录。

## Q11：图表为空怎么办？

先区分是哪一类页面：

- 独立 HTML 报告页
- Web 报告中心首页 / 扫描详情页

当前版本中：

- 独立报告使用本地 `assets/`
- Web 报告中心公共样式已经改为内联

如果独立报告图表不显示，优先检查是否拷贝了整个报告目录，而不是只拷 `report.html`。

## Q12：为什么报告里会出现“需要手动确认”？

因为系统当前认为证据不足以给出高置信结论。

常见触发条件：

- 服务版本缺失
- 规则要求版本比较
- 指纹不完整

这属于有意设计的误报控制机制。

## Q13：为什么启用弱口令尝试时日志里提示缺少依赖？

因为：

- SSH 弱口令依赖 `paramiko`
- MySQL 弱口令依赖 `pymysql`

缺依赖时，对应协议会被跳过，但 GUI 主流程不会因此崩掉。

## Q14：能不能直接拿第三方公网靶场来扫？

不建议，也不应默认这么做。

正确做法是：

1. 只扫描你自己控制或明确授权的目标
2. 先看 [SECURITY_ETHICS.md](./SECURITY_ETHICS.md)
3. 再看 [external_validation_manual.md](./external_validation_manual.md)
